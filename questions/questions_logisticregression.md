## 1 База
1. **Что такое логистическая регрессия?** 
Статистическая модель и алгоритм машинного обучения для предсказания вероятности принадлежности объекта к определенному классу.
2. **Какую задачу она решает?**
Задачу классификации.
3. **Почему, несмотря на название, это метод классификации?**
Потому что итоговым результатом работы алгоритма является отнесение объекта к одному из дискретных классов на основе предсказанной вероятности и заданного порога, а не прогнозирование непрерывной величины.
4. **Чем отличается от линейной регрессии?**
Линейная регрессия предсказывает непрерывные значения от $-\infty$ до $+\infty$. Логистическая регрессия предсказывает значения строго на отрезке $[0, 1]$, пропуская линейную комбинацию признаков через нелинейную функцию активации.
5. **Что является выходом модели?**
Вероятность принадлежности входного объекта к положительному классу:

$$p = \frac{1}{1 + e^{-(w^T x + b)}}$$

6. **Что такое вероятность класса?**
Количественная оценка степени уверенности модели в том, что данный объект принадлежит к конкретному классу, выраженная числом в диапазоне от 0 до 1.
7. **Что такое бинарная классификация?**
Задача распределения объектов ровно на два взаимоисключающих класса.
8. **Что такое многоклассовая логистическая регрессия?**
Обобщение алгоритма на задачи с тремя и более непересекающимися классами. Для вычисления вероятностей вместо сигмоиды применяется функция Softmax:

$$P(y=k \mid x) = \frac{e^{w_k^T x}}{\sum_{j=1}^{K} e^{w_j^T x}}$$

9. **Что такое коэффициенты модели?**
Обучаемые весовые параметры, которые умножаются на значения соответствующих признаков и определяют силу и направление влияния каждого признака на предсказание.
10. **Как интерпретировать коэффициенты?**
Коэффициент при признаке показывает изменение логарифма отношения шансов при изменении этого признака на одну единицу. Экспонента коэффициента показывает, во сколько раз изменится само отношение шансов:

$$\frac{p}{1-p} = e^{w_0 + w_1 x_1 + \dots + w_n x_n}$$

## 2 Математические основы
11. **Что такое сигмоида?**
Гладкая монотонная $S$-образная функция, отображающая любое вещественное число в интервал $(0, 1)$.

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

12. **Почему используется сигмоида?**
Она непрерывна и дифференцируема на всей числовой оси, отображает диапазон $(-\infty, +\infty)$ в область допустимых значений вероятности $(0, 1)$, а её производная легко выражается через значение самой функции.
13. **Что такое logit?**
Натуральный логарифм отношения шансов (log-odds), который выступает обратно-симметричной функцией по отношению к сигмоиде.

$$\text{logit}(p) = \ln\left(\frac{p}{1-p}\right)$$

14. **Что такое odds?**
Шансы (odds) — это отношение вероятности наступления события к вероятности его ненаступления.

$$\text{Odds} = \frac{p}{1 - p}$$

15. **Что такое log-odds?**
Натуральный логарифм шансов. В логистической регрессии именно log-odds моделируется как линейная комбинация входных признаков.

$$\text{Log-Odds} = \ln\left(\frac{p}{1 - p}\right) = w^T x + b$$

16. **Как связаны вероятность и logit?**
Функция logit связывает вероятность $p \in (0, 1)$ с линейной частью модели $z \in (-\infty, +\infty)$, а сигмоида выполняет обратное преобразование.

$$z = \text{logit}(p) \iff p = \sigma(z)$$

17. **Почему сигмоида ограничивает выход интервалом (0,1)?**
Поскольку экспонента $e^{-z} > 0$ для всех $z \in \mathbb{R}$, знаменатель $1 + e^{-z}$ строго больше числителя $1$ и строго больше $1$, что математически задаёт пределы $\lim_{z \to -\infty} \sigma(z) = 0$ и $\lim_{z \to +\infty} \sigma(z) = 1$.
18. **Почему нельзя использовать линейную регрессию для вероятностей?**
Линейная регрессия может выдавать значения за пределами интервала $[0, 1]$, а также нарушает предпосылку о гомоскедастичности, так как дисперсия бинарной случайной величины зависит от её математического ожидания.
19. **Как выглядит функция модели?**
Вероятность принадлежности объекта к положительному классу выражается через линейную комбинацию признаков:

$$P(y = 1 \mid x) = \frac{1}{1 + e^{-(w^T x + b)}}$$

20. **Как интерпретировать отношение шансов (odds ratio)?**
Отношение шансов показывает, во сколько раз изменятся шансы наступления события $y = 1$ при увеличении выбранного признака на единицу при неизменности остальных параметров.

$$\text{OR} = \frac{\text{Odds}(x_i + 1)}{\text{Odds}(x_i)} = e^{w_i}$$

## 3 Обучение
21. **Почему MSE плохо подходит?**
Из-за нелинейности сигмоиды функция потерь MSE становится невыпуклой со множеством локальных минимумов, а также демонстрирует эффект исчезновения градиентов при больших ошибках классификации.
22. **Что такое Binary Cross-Entropy?**
Функция потерь для оценки качества модели бинарной классификации, штрафующая отклонение предсказанной вероятности от истинной метки.

$$L = - [y \ln(p) + (1 - y) \ln(1 - p)]$$

23. **Что такое Log Loss?**
Метрика качества и функция потерь, представляющая собой усредненную бинарную кросс-энтропию по всей обучающей выборке.

$$\text{LogLoss} = -\frac{1}{N} \sum_{i=1}^{N} \left[ y_i \ln(p_i) + (1 - y_i) \ln(1 - p_i) \right]$$

24. **Как выглядит функция правдоподобия?**
Произведение вероятностей реализации наблюдаемых меток классов для всех объектов выборки при заданных весах.

$$L(w) = \prod_{i=1}^{N} p_i^{y_i} (1 - p_i)^{1 - y_i}$$

25. **Что такое Maximum Likelihood Estimation (MLE)?**
Метод оценивания параметров модели путем нахождения весов, максимизирующих логарифмическую функцию правдоподобия.

$$\hat{w} = \arg\max_{w} \sum_{i=1}^{N} \left[ y_i \ln(p_i) + (1 - y_i) \ln(1 - p_i) \right]$$

26. **Почему аналитического решения нет?**
Система уравнений, получаемая при приравнивании градиента Log Loss к нулю, является нелинейной (трансцендентной) относительно весов из-за наличия сигмоиды и не имеет решения в замкнутом виде.
27. **Почему используют Gradient Descent?**
Из-за отсутствия аналитического решения итерационные численные методы позволяют с заданной точностью найти оптимальные параметры, гарантированно сходясь к единственному глобальному минимуму.
28. **Что такое градиент функции потерь?**
Вектор частных производных функции потерь по весовым параметрам модели, определяющий направление наибыстрейшего роста ошибки.

$$\nabla_w L = \frac{1}{N} \sum_{i=1}^{N} (p_i - y_i) x_i$$

29. **Как влияет learning rate?**
Коэффициент определяющий размер шага при обновлении весов: завышенное значение ведет к расходимости алгоритма, заниженное — к слишком медленной сходимости.
30.  **Почему функция потерь выпуклая?**
Гессиан (матрица вторых производных) функции Log Loss является положительно полуопределенной матрицей для любых значений весов.

$$H = \frac{1}{N} X^T D X \succeq 0, \quad D_{ii} = p_i (1 - p_i)$$

## 4 Метрики
31. **Что такое Accuracy?**
Доля правильно классифицированных объектов среди общего числа объектов выборки.

$$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$

32. **Когда Accuracy бесполезна?**
При сильном дисбалансе классов, а также при существенной несимметричности ценности ошибок первого и второго рода.
33. **Что такое Precision?**
Доля объектов, реально принадлежащих к положительному классу, среди всех объектов, классифицированных моделью как положительные.

$$\text{Precision} = \frac{TP}{TP + FP}$$

34. **Что такое Recall?**
Доля найденных моделью объектов положительного класса относительно общего реального числа объектов положительного класса.

$$\text{Recall} = \frac{TP}{TP + FN}$$

35. **Что такое F1-score?**
Гармоническое среднее между Precision и Recall, оценивающее баланс между точностью и полнотой.

$$F_1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$$

36. **Что такое Specificity?**
Специфичность — доля верно классифицированных отрицательных объектов относительно общего числа реальных объектов отрицательного класса.

$$\text{Specificity} = \frac{TN}{TN + FP}$$

37. **Что такое ROC-кривая?**
График зависимости доли истинно положительных классификаций (TPR) от доли ложноположительных классификаций (FPR) при варьировании порога бинаризации.

$$\text{TPR} = \frac{TP}{TP + FN}, \quad \text{FPR} = \frac{FP}{FP + TN}$$

38. **Что такое AUC-ROC?**
Площадь под ROC-кривой, оценивающая способность модели правильно ранжировать объекты по вероятностям принадлежности к положительному классу.

$$\text{AUC-ROC} = \int_{0}^{1} \text{TPR}(\text{FPR}) \, d(\text{FPR})$$

39. **Что такое PR-кривая?**
График зависимости Precision от Recall при изменении порога отсечения модели.
40. **Когда PR-кривая лучше ROC?**
В задачах с сильным дисбалансом классов, когда положительный класс мал по объему, так как Precision не маскируется большим числом истинно отрицательных объектов ($TN$).

## 5 Порог классификации
41. **Почему по умолчанию используют порог 0.5?**
Порог 0.5 является естественной границей в условиях равной вероятности классов и одинаковой стоимости ошибок первого и второго рода, что соответствует значению линейной комбинации признаков $z = 0$.
1.  **Можно ли менять threshold?**
Да, порог классификации является настраиваемым гиперпараметром, который можно адаптировать под требования задачи.
1.  **Как threshold влияет на Precision и Recall?**
Порог определяет баланс между метриками: его повышение увеличивает Precision и уменьшает Recall, а понижение снижает Precision и увеличивает Recall.
1.  **Что происходит при уменьшении threshold?**
Модель чаще относят объекты к положительному классу, что увеличивает количество $TP$ и $FP$, повышает Recall, но снижает Precision.
1.  **Что происходит при увеличении threshold?**
Модель реже относит объекты к положительному классу, что уменьшает количество $FP$ и $TP$, увеличивает Precision, но снижает Recall.
1.  **Как выбрать оптимальный threshold?**
Путем минимизации функции суммарных финансовых или операционных потерь либо максимизацией выбранной метрики (например, $F_1$-score или индекса Юдена):

$$J(t) = \text{TPR}(t) - \text{FPR}(t)$$

47. **Что такое матрица ошибок (Confusion Matrix)?**
Таблица размера $2 \times 2$, отображающая количество верных и неверных предсказаний модели для каждого из двух классов.
48. **Как вычисляются TP, FP, TN, FN?**
Подсчетом элементов на основе сравнения предсказанной вероятности $\hat{p}_i$ с порогом $t$ и истинной меткой $y_i$:

$$TP = \sum_{i=1}^N \mathbb{I}(y_i = 1 \land \hat{p}_i \ge t)$$

$$FP = \sum_{i=1}^N \mathbb{I}(y_i = 0 \land \hat{p}_i \ge t)$$

$$TN = \sum_{i=1}^N \mathbb{I}(y_i = 0 \land \hat{p}_i < t)$$

$$FN = \sum_{i=1}^N \mathbb{I}(y_i = 1 \land \hat{p}_i < t)$$

49. **Как связаны ROC и threshold?**
Каждая точка ROC-кривой представляет собой пару значений $(\text{FPR}, \text{TPR})$, полученную при конкретном фиксированном значении порога $t \in [0, 1]$.
50. **Почему threshold зависит от бизнес-задачи?**
Потому что в разных предметных областях стоимость ошибки первого рода ($FP$) и второго рода ($FN$) существенным образом различается.

## 6 Регуляризация 
51. **Зачем нужна регуляризация?**
Для предотвращения переобучения модели, уменьшения её сложности и улучшения обобщающей способности на новых данных за счёт наложения штрафа на величину весовых коэффициентов.
52. **Что такое L1-регуляризация?**
Метод добавления к функции потерь штрафа, пропорционального сумме абсолютных значений весовых коэффициентов (L1-норма).

$$L_{L1}(w) = L(w) + \lambda \sum_{j=1}^{p} \vert{}w_j\vert{}$$

53. **Что такое L2-регуляризация?**
Метод добавления к функции потерь штрафа, пропорционального сумме квадратов весовых коэффициентов (L2-норма).

$$L_{L2}(w) = L(w) + \lambda \sum_{j=1}^{p} w_j^2$$

54. **Чем Ridge отличается от Lasso?**
Ridge использует L2-штраф и уменьшает веса пропорционально их величине, не зануляя их полностью, тогда как Lasso использует L1-штраф и зануляет часть коэффициентов, выполняя отбор признаков.
55. **Как регуляризация влияет на коэффициенты?**
Уменьшает абсолютные значения весовых коэффициентов (смещает их в сторону нуля), снижая чувствительность модели к флуктуациям и шуму в обучающих данных.
56. **Почему L1 выполняет feature selection?**
Из-за геометрической формы области допустимых значений L1-нормы (ромб/октаэдр), имеющей угловые точки на осях координат. Точки касания линий уровня функции потерь с этой областью чаще всего приходятся на оси, обнуляя соответствующие веса.
57. **Почему нужна стандартизация?**
Так как штраф регуляризации одинаково применяется ко всем весам, признаки с более крупным масштабом имеют меньшие по модулю веса и подвергаются слабейшему штрафованию, что искажает результаты оптимизации.
58. **Как выбирать коэффициент регуляризации?**
С помощью кросс-валидации на обучающей выборке путём перебора значений по сетке (Grid Search) или случайным поиском (Random Search).
59. **Что такое Elastic Net?**
Комбинированный метод регуляризации, объединяющий L1- и L2-штрафы с настраиваемым балансом между ними.

$$L_{\text{ElasticNet}}(w) = L(w) + \lambda \left( \alpha \sum_{j=1}^{p} \vert{}w_j\vert{} + \frac{1 - \alpha}{2} \sum_{j=1}^{p} w_j^2 \right)$$

60. **Как регуляризация борется с переобучением?**
Ограничивает норму вектора весов, запрещая модели строить слишком сложные разделяющие поверхности, что снижает дисперсию (variance) оценки ценой незначительного увеличения смещения (bias).

## 7 Статистика
61. **Какие assumptions есть у логистической регрессии?**
Бинарность или дискретность целевой переменной, независимость наблюдений, линейная связь между независимыми признаками и log-odds, отсутствие сильной мультиколлинеарности между признаками и достаточный объем выборки.
62. **Что означает линейность в log-odds?**
Это означают, что натуральный логарифм отношения шансов выражается в виде линейной комбинации входных признаков:

$$\ln\left(\frac{p}{1-p}\right) = w_0 + w_1 x_1 + \dots + w_n x_n$$

63. **Что такое мультиколлинеарность?**
Наличие высокой линейной корреляции или полной зависимости между двумя или более независимыми признаками в модели.
64. **Как проверить значимость коэффициентов?**
Путем проверки статистических гипотез о равенстве коэффициента нулю с использованием критерия Вальда (Wald test) или теста отношения правдоподобия (Likelihood Ratio Test).
65. **Что такое Wald test?**
Статистический тест для проверки гипотезы $H_0: w_j = 0$, оценивающий отношение оценки коэффициента к его стандартной ошибке:

$$W = \frac{\hat{w}_j}{\text{SE}(\hat{w}_j)}$$

66. **Что такое Likelihood Ratio Test?**
Статистический тест, сравнивающий значение логарифма правдоподобия полной модели со значением логарифма правдоподобия усеченной модели без проверяемого коэффициента:

$$\text{LRT} = -2 \ln\left(\frac{L_0}{L_1}\right) = 2(\ln L_1 - \ln L_0)$$

67. **Что такое доверительный интервал коэффициента?**
Интервал значений, рассчитываемый по формуле и накрывающий истинное значение параметра с заданной доверительной вероятностью:

$$\hat{w}_j \pm z_{1-\alpha/2} \cdot \text{SE}(\hat{w}_j)$$

68. **Что означает odds ratio > 1?**
Увеличение значения данного признака на одну единицу приводит к росту шансов наступления целевого события ($y = 1$).
69. **Что означает odds ratio < 1?**
Увеличение значения данного признака на одну единицу приводит к снижению шансов наступления целевого события ($y = 1$).
70. **Почему корреляция не означает причинность?**
Потому что наличие статистической взаимосвязи между переменными не гарантирует прямого причинно-следственного механизма и может быть вызвано влиянием неучтенных третьих факторов (конфаундеров) или обратной причинностью.

## 8 Продвинутые вопросы
71. **Выведите функцию Log Loss.**
Для бинарной случайной величины $y_i \in \{0, 1\}$ функция правдоподобия одного наблюдения имеет вид:

$$P(y_i \mid x_i) = p_i^{y_i} (1 - p_i)^{1 - y_i}$$

Функция правдоподобия для всей выборки из $N$ независимых наблюдений:

$$L(w) = \prod_{i=1}^{N} p_i^{y_i} (1 - p_i)^{1 - y_i}$$

Логарифм функции правдоподобия:

$$\ln L(w) = \sum_{i=1}^{N} \left[ y_i \ln p_i + (1 - y_i) \ln(1 - p_i) \right]$$

Минимизация отрицательного усредненного логарифма правдоподобия даёт функцию Log Loss:

$$\text{LogLoss} = -\frac{1}{N} \sum_{i=1}^{N} \left[ y_i \ln p_i + (1 - y_i) \ln(1 - p_i) \right]$$

72. **Докажите выпуклость Log Loss.**
Первая производная Log Loss по весам имеет вид:

$$\nabla L(w) = \frac{1}{N} X^T (p - y)$$

Матрица вторых производных (Гессиан) рассчитывается как:

$$H = \nabla^2 L(w) = \frac{1}{N} X^T D X$$

где $D$ — диагональная матрица с элементами $D_{ii} = p_i(1 - p_i) > 0$. Для любого ненулевого вектора $v \in \mathbb{R}^d$:

$$v^T H v = \frac{1}{N} (X v)^T D (X v) \ge 0$$

Поскольку Гессиан неотрицательно определен ($H \succeq 0$) на всем пространстве параметров, функция Log Loss является выпуклой.

73. **Почему MLE эквивалентен минимизации Cross-Entropy?**
Максимизация логарифмического правдоподобия в методе MLE математически эквивалентна минимизации функции кросс-энтропии, так как задачи отличаются лишь умножением на константу $-\frac{1}{N}$:

$$\arg\max_w \ln L(w) = \arg\min_w \left( -\frac{1}{N} \ln L(w) \right) = \arg\min_w \text{CrossEntropy}(w)$$

74. **Почему отсутствует closed-form решение?**
Условие первого порядка для поиска минимума $\nabla_w L(w) = 0$ приводит к системе трансцендентных уравнений из-за наличия нелинейной экспоненциальной функции в сигмоиде:

$$\frac{1}{N} \sum_{i=1}^{N} \left( \frac{1}{1 + e^{-w^T x_i}} - y_i \right) x_i = 0$$

Данную систему невозможно выразить в виде явного аналитического решения относительно весов $w$.

75. **Как вычисляется Hessian?**
Гессиан вычисляется как произведение матрицы признаков и диагональной матрицы весов:

$$H = \frac{1}{N} X^T D X$$

где $X$ — матрица объектов-признаков размера $N \times d$, а $D$ — диагональная матрица размера $N \times N$ со значениями $D_{ii} = p_i(1 - p_i) = \sigma(w^T x_i)(1 - \sigma(w^T x_i))$.

76. **Что такое Newton-Raphson?**
Итерационный метод оптимизации второго порядка, использующий градиент и обратную матрицу Гессиана для обновления вектора весов:

$$w^{(k+1)} = w^{(k)} - H^{-1} \nabla L(w^{(k)})$$

77. **Что такое Iteratively Reweighted Least Squares (IRLS)?**
Алгоритм численной оптимизации логистической регрессии, полученный подстановкой градиента и Гессиана в шаг метода Ньютона-Рафсона, сводящий каждую итерацию к решению задачи взвешенных наименьших квадратов:

$$w^{(k+1)} = (X^T D X)^{-1} X^T D z$$

где $z = X w^{(k)} + D^{-1}(y - p)$ — скорректированная переменная отклика, а $D_{ii} = p_i(1 - p_i)$ — диагональная матрица весов.

78. **Почему логистическая регрессия является GLM?**
Она удовлетворяет всем трём требованиям обобщенных линейных моделей: распределение целевой переменной $y \mid x \sim \text{Bernoulli}(p)$ принадлежит экспоненциальному семейству, математическое ожидание $\mu = p$ связано с линейным предиктором $\eta = w^T x$ через каноническую функцию связи $\eta = \text{logit}(\mu)$.
79. **Как связана с экспоненциальным семейством распределений?**
Распределение Бернулли записывается в плотности экспоненциального семейства:

$$P(y \mid \eta) = \exp\left( y \eta - \ln(1 + e^\eta) \right)$$

где естественный параметр $\eta = \ln\left(\frac{p}{1-p}\right) = w^T x$. Использование канонической функции связи задает прямую линейную зависимость между естественным параметром распределения и признаками объекта.

80. **Как выполняется многоклассовая классификация (Softmax Regression)?**
Вероятность принадлежности объекта $x$ к классу $k \in \{1, \dots, K\}$ вычисляется путем прохождения линейных комбинаций с индивидуальными векторами весов $w_k$ через функцию Softmax:

$$P(y = k \mid x) = \frac{e^{w_k^T x}}{\sum_{j=1}^{K} e^{w_j^T x}}$$

81. **Выведите сигмоидальную функцию из logit-преобразования.**

Logit-преобразование определяет зависимость между вероятностью $p \in (0, 1)$ и линейной комбинацией признаков $z \in \mathbb{R}$:

$$\text{logit}(p) = \ln \left( \frac{p}{1 - p} \right) = z$$

Для вывода сигмоидальной функции выразим вероятность $p$ через $z$. Возьмём экспоненту от обеих частей уравнения:

$$\frac{p}{1 - p} = e^z$$

Умножим обе части уравнения на $(1 - p)$:

$$p = e^z (1 - p)$$

Раскроем скобки в правой части:

$$p = e^z - p e^z$$

Перенесём все слагаемые с $p$ в левую часть уравнения:

$$p + p e^z = e^z$$

Вынесем $p$ за скобки:

$$p (1 + e^z) = e^z$$

Разделим обе части на $(1 + e^z)$:

$$p = \frac{e^z}{1 + e^z}$$

Разделим числитель и знаменатель дроби на $e^z$:

$$p = \frac{1}{1 + e^{-z}}$$

Полученное выражение $p = \sigma(z)$ представляет собой сигмоидальную функцию.

82. **Докажите, что сигмоида принимает значения только в (0,1).**

Сигмоидальная функция задаётся формулой:

$$\sigma(z) = \frac{1}{1 + e^{-z}}, \quad z \in \mathbb{R}$$

Для любого действительного значения $z \in \mathbb{R}$ функция показательной степени строго положительна:

$$e^{-z} > 0$$

Прибавим $1$ к обеим частям неравенства:

$$1 + e^{-z} > 1$$

Так как знаменатель $1 + e^{-z}$ строго больше $1$, величина, обратная знаменателю, будет строго меньше $1$:

$$\frac{1}{1 + e^{-z}} < 1$$

С другой стороны, поскольку числитель $1 > 0$ и знаменатель $1 + e^{-z} > 0$, дробь всегда строго положительна:

$$\frac{1}{1 + e^{-z}} > 0$$

Объединяя оба неравенства, получаем:

$$0 < \sigma(z) < 1 \quad \forall z \in \mathbb{R}$$

Исследуем пределы функции на бесконечности:

$$\lim_{z \to +\infty} \sigma(z) = \lim_{z \to +\infty} \frac{1}{1 + e^{-z}} = \frac{1}{1 + 0} = 1$$

$$\lim_{z \to -\infty} \sigma(z) = \lim_{z \to -\infty} \frac{1}{1 + e^{-z}} = \frac{1}{1 + \infty} = 0$$

Поскольку функция $\sigma(z)$ непрерывна и строго монотонна на всей области определения $\mathbb{R}$, её областью значений является открытый интервал $(0, 1)$.

83. **Найдите производную сигмоиды.**

Представим сигмоиду в виде степенной функции:

$$\sigma(z) = (1 + e^{-z})^{-1}$$

Применим правило дифференцирования сложной функции $\frac{d}{dz} [f(g(z))] = f'(g(z)) \cdot g'(z)$:

$$\frac{d}{dz} \sigma(z) = -1 \cdot (1 + e^{-z})^{-2} \cdot \frac{d}{dz} (1 + e^{-z})$$

Вычислим производную внутренней функции:

$$\frac{d}{dz} (1 + e^{-z}) = 0 + e^{-z} \cdot (-1) = -e^{-z}$$

Подставим полученную производную внутренней функции:

$$\frac{d}{dz} \sigma(z) = -1 \cdot (1 + e^{-z})^{-2} \cdot (-e^{-z}) = \frac{e^{-z}}{(1 + e^{-z})^2}$$

84. **Докажите, что $\sigma'(z) = \sigma(z)(1 - \sigma(z))$.**

Из предыдущего вывода производная сигмоиды имеет вид:

$$\sigma'(z) = \frac{e^{-z}}{(1 + e^{-z})^2}$$

Преобразуем числитель дроби, прибавив и вычтя единицу:

$$e^{-z} = (1 + e^{-z}) - 1$$

Подставим это выражение в производную и разложим на сумму двух дробей:

$$\sigma'(z) = \frac{(1 + e^{-z}) - 1}{(1 + e^{-z})^2} = \frac{1 + e^{-z}}{(1 + e^{-z})^2} - \frac{1}{(1 + e^{-z})^2}$$

Сократим первую дробь на $(1 + e^{-z})$:

$$\sigma'(z) = \frac{1}{1 + e^{-z}} - \frac{1}{(1 + e^{-z})^2}$$

Вынесем общий множитель $\frac{1}{1 + e^{-z}}$ за скобки:

$$\sigma'(z) = \frac{1}{1 + e^{-z}} \left( 1 - \frac{1}{1 + e^{-z}} \right)$$

Учитывая, что $\sigma(z) = \frac{1}{1 + e^{-z}}$, получаем:

$$\sigma'(z) = \sigma(z) (1 - \sigma(z))$$

85. **Что такое logit-функция и почему она является обратной к сигмоиде?**

Logit-функция — это математическая функция, определяемая как натуральный логарифм отношения шансов для вероятности $p \in (0, 1)$:

$$\text{logit}(p) = \ln \left( \frac{p}{1 - p} \right)$$

Две функции $f$ и $g$ являются взаимно обратными, если $f(g(x)) = x$ и $g(f(x)) = x$.

Докажем, что $\sigma(\text{logit}(p)) = p$:

$$\sigma(\text{logit}(p)) = \frac{1}{1 + e^{-\text{logit}(p)}} = \frac{1}{1 + e^{-\ln\left(\frac{p}{1-p}\right)}}$$

Используя свойство экспоненты и логарифма $e^{-\ln(a)} = \frac{1}{a}$:

$$e^{-\ln\left(\frac{p}{1-p}\right)} = \frac{1}{\frac{p}{1-p}} = \frac{1 - p}{p}$$

Подставим результат в знаменатель:

$$\sigma(\text{logit}(p)) = \frac{1}{1 + \frac{1 - p}{p}} = \frac{1}{\frac{p + 1 - p}{p}} = \frac{1}{\frac{1}{p}} = p$$

Докажем обратное соотношение $\text{logit}(\sigma(z)) = z$:

$$\text{logit}(\sigma(z)) = \ln \left( \frac{\sigma(z)}{1 - \sigma(z)} \right)$$

Вычислим выражение $1 - \sigma(z)$:

$$1 - \sigma(z) = 1 - \frac{1}{1 + e^{-z}} = \frac{1 + e^{-z} - 1}{1 + e^{-z}} = \frac{e^{-z}}{1 + e^{-z}}$$

Найдем отношение $\frac{\sigma(z)}{1 - \sigma(z)}$:

$$\frac{\sigma(z)}{1 - \sigma(z)} = \frac{\frac{1}{1 + e^{-z}}}{\frac{e^{-z}}{1 + e^{-z}}} = \frac{1}{e^{-z}} = e^z$$

Подставим результат в логарифм:

$$\text{logit}(\sigma(z)) = \ln(e^z) = z$$

Тождества $\sigma(\text{logit}(p)) = p$ и $\text{logit}(\sigma(z)) = z$ доказаны.

86. **Выведите функцию правдоподобия для логистической регрессии.**

Пусть целевая переменная $y_i \in \{0, 1\}$ распределена по закону Бернулли с параметром $p_i = P(y_i = 1 \mid x_i; w)$.

Функция вероятности для одного наблюдения $i$ записывается в виде:

$$P(y_i \mid x_i; w) = \begin{cases} p_i, & \text{если } y_i = 1 \\ 1 - p_i, & \text{если } y_i = 0 \end{cases}$$

Запишем эту функцию единой аналитической формулой:

$$P(y_i \mid x_i; w) = p_i^{y_i} (1 - p_i)^{1 - y_i}$$

В предположении о независимости наблюдений в выборке из $N$ объектов, joint-вероятность (функция правдоподобия) равна произведению вероятностей каждого наблюдения:

$$L(w) = \prod_{i=1}^{N} P(y_i \mid x_i; w) = \prod_{i=1}^{N} p_i^{y_i} (1 - p_i)^{1 - y_i}$$

Подставляя вместо $p_i$ модельную вероятность $p_i = \sigma(w^T x_i)$, получаем итоговую функцию правдоподобия:

$$L(w) = \prod_{i=1}^{N} \left( \sigma(w^T x_i) \right)^{y_i} \left( 1 - \sigma(w^T x_i) \right)^{1 - y_i}$$

87. **Почему логарифмируют функцию правдоподобия?**
88. **Предотвращение численного недополнения (Numerical Underflow):** Произведение $N$ вероятностей $p_i \in (0, 1)$ при больших $N$ стремится к нулю гораздо быстрее, чем позволяет точность представления чисел с плавающей запятой в ЭВМ, что приводит к обнулению значения $L(w)$. Логарифм переводит произведение в сумму, сохраняя устойчивые масштабы чисел.
89. **Упрощение дифференцирования:** Вычисление градиента от суммы функций $\sum f_i(w)$ математически проще, чем применение правила произведения функций к $\prod f_i(w)$.
90. **Сохранение точки экстремума (Монотонность):** Натуральный логарифм $\ln(x)$ — строго возрастающая функция на всей области определения $x > 0$. Следовательно, операция логарифмирования не меняет точку максимума функции:

$$\arg\max_w L(w) = \arg\max_w \ln L(w)$$

88. **Выведите log-likelihood.**

Логарифмическая функция правдоподобия $\ell(w)$ получается примянением натурального логарифма к функции правдоподобия $L(w)$:

$$\ell(w) = \ln L(w) = \ln \left( \prod_{i=1}^{N} p_i^{y_i} (1 - p_i)^{1 - y_i} \right)$$

Используя свойство логарифма произведения $\ln(a \cdot b) = \ln a + \ln b$, перейдём от произведения к сумме:

$$\ell(w) = \sum_{i=1}^{N} \ln \left( p_i^{y_i} (1 - p_i)^{1 - y_i} \right)$$

Используя свойство логарифма степени $\ln(a^b) = b \ln a$:

$$\ell(w) = \sum_{i=1}^{N} \left[ y_i \ln(p_i) + (1 - y_i) \ln(1 - p_i) \right]$$

Выразим $\ell(w)$ явно через веса $w$. Учитывая, что $p_i = \sigma(z_i)$ и $1 - p_i = \sigma(-z_i)$, где $z_i = w^T x_i$:

$$\ln(p_i) = \ln\left(\frac{1}{1 + e^{-z_i}}\right) = -\ln(1 + e^{-z_i})$$

$$\ln(1 - p_i) = \ln\left(\frac{e^{-z_i}}{1 + e^{-z_i}}\right) = -z_i - \ln(1 + e^{-z_i})$$

Подставим эти выражения в сумму:

$$\ell(w) = \sum_{i=1}^{N} \left[ -y_i \ln(1 + e^{-z_i}) + (1 - y_i)(-z_i - \ln(1 + e^{-z_i})) \right]$$

$$\ell(w) = \sum_{i=1}^{N} \left[ y_i z_i - z_i - \ln(1 + e^{-z_i}) \right] = \sum_{i=1}^{N} \left[ y_i (w^T x_i) - \ln(1 + e^{w^T x_i}) \right]$$

---

89. **Покажите, что минимизация Cross-Entropy эквивалентна максимизации log-likelihood.**

Функция потерь бинарной кросс-энтропии (Log Loss) рассчитывается как среднее отрицательное логарифмическое правдоподобие по всей выборке:

$$J(w) = -\frac{1}{N} \sum_{i=1}^{N} \left[ y_i \ln(p_i) + (1 - y_i) \ln(1 - p_i) \right]$$

Выразим $J(w)$ через функцию log-likelihood $\ell(w)$:

$$J(w) = -\frac{1}{N} \ell(w)$$

Запишем задачу минимизации эмпирического риска $J(w)$:

$$w^* = \arg\min_w J(w) = \arg\min_w \left( -\frac{1}{N} \ell(w) \right)$$

Поскольку $N > 0$, умножение на положительную константу $\frac{1}{N}$ не меняет положение точки минимума. Переход от оптимизации отрицания функции $-f(w)$ к самой функции $f(w)$ меняет знак операции оптимизации с $\arg\min$ на $\arg\max$:

$$\arg\min_w \left( -\frac{1}{N} \ell(w) \right) = \arg\max_w \ell(w)$$

Следовательно:

$$\arg\min_w J(w) = \arg\max_w \ell(w)$$

Задачи минимизации функции потерь Cross-Entropy и максимизации функции log-likelihood приводят к идентичному вектору параметров $w^*$.

90. **Почему аналитического решения для логистической регрессии не существует?**

Для поиска аналитического решения необходимо найти вектор весов $w$, при котором градиент функции потерь равен нулевому вектору:

$$\nabla_w J(w) = 0$$

Вычислим градиент $\nabla_w J(w)$:

$$\nabla_w J(w) = \frac{1}{N} \sum_{i=1}^{N} (p_i - y_i) x_i = \frac{1}{N} \sum_{i=1}^{N} \left( \frac{1}{1 + e^{-w^T x_i}} - y_i \right) x_i$$

Приравняем градиент к нулю:

$$\sum_{i=1}^{N} \frac{1}{1 + e^{-w^T x_i}} x_i = \sum_{i=1}^{N} y_i x_i$$

Данное уравнение относительно весов $w$ является системой нелинейных трансцендентных уравнений, поскольку неизвестный параметр $w$ находится в показателе экспоненты внутри сигмоиды.

В отличие от линейной регрессии, где приравнивание градиента к нулю дает систему линейных алгебраических уравнений $X^T X w = X^T y$ с явным решением $w = (X^T X)^{-1} X^T y$, данную трансцендентную систему невозможно разрешить аналитически относительно $w$ с помощью конечного числа алгебраических операций. Решение находится исключительно численными итерационными методами.

## 10 Оптимизация 
91. **Выведите градиент Log Loss по параметрам.**

Функция потерь Log Loss для $N$ наблюдений определяется следующим образом:

$$J(w) = -\frac{1}{N} \sum_{i=1}^{N} \left[ y_i \ln(p_i) + (1 - y_i) \ln(1 - p_i) \right]$$

где $p_i = \sigma(z_i)$ и $z_i = w^T x_i$.

Для нахождения частной производной по вектору весов $w$ применим правило дифференцирования сложной функции (Chain Rule) к $i$-му слагаемому:

$$\frac{\partial J_i}{\partial w} = \frac{\partial J_i}{\partial p_i} \cdot \frac{\partial p_i}{\partial z_i} \cdot \frac{\partial z_i}{\partial w}$$

1. Вычислим частную производную $J_i$ по $p_i$:

$$\frac{\partial J_i}{\partial p_i} = -\left( \frac{y_i}{p_i} - \frac{1 - y_i}{1 - p_i} \right) = -\frac{y_i(1 - p_i) - (1 - y_i)p_i}{p_i(1 - p_i)} = \frac{p_i - y_i}{p_i(1 - p_i)}$$

2. Вычислим производную сигмоиды $p_i = \sigma(z_i)$ по $z_i$:

$$\frac{\partial p_i}{\partial z_i} = p_i (1 - p_i)$$

3. Вычислим градиент линейного предиктора $z_i = w^T x_i$ по $w$:

$$\frac{\partial z_i}{\partial w} = x_i$$

Перемножим полученные частные производные для $i$-го объекта:

$$\frac{\partial J_i}{\partial w} = \frac{p_i - y_i}{p_i(1 - p_i)} \cdot p_i(1 - p_i) \cdot x_i = (p_i - y_i) x_i$$

Усредняя по всем $N$ наблюдениям выборки, получаем итоговое выражение для градиента Log Loss:

$$\nabla_w J(w) = \frac{1}{N} \sum_{i=1}^{N} (p_i - y_i) x_i$$

---

92. **Запишите градиент в матричной форме.**

Определим основные матрицы и векторы:

* $X \in \mathbb{R}^{N \times d}$ — матрица признаков, где $i$-я строка равна $x_i^T$;
* $y \in \mathbb{R}^N$ — вектор истинных меток классов $y = (y_1, y_2, \dots, y_N)^T$;
* $p \in \mathbb{R}^N$ — вектор предсказанных вероятностей $p = (p_1, p_2, \dots, p_N)^T$, где $p_i = \sigma(X_i w)$.

Сумму скалярных произведений в градиенте $\sum_{i=1}^{N} (p_i - y_i) x_i$ можно записать как линейную комбинацию столбцов матрицы $X^T$, умноженную на вектор ошибок предсказания $(p - y)$:

$$\nabla_w J(w) = \frac{1}{N} X^T (p - y)$$

Размерность вектора градиента составляет $d \times 1$, что соответствует размерности вектора параметров $w$.

---

93. **Выведите матрицу Гессе.**

Матрица Гессе (Гессиан) $H = \nabla_w^2 J(w)$ представляет собой матрицу вторых частных производных размера $d \times d$.

Возьмём производную от матричного выражения градиента по вектору весов $w$:

$$H = \frac{\partial}{\partial w} \left( \nabla_w J(w) \right) = \frac{\partial}{\partial w} \left( \frac{1}{N} X^T (p - y) \right) = \frac{1}{N} X^T \frac{\partial p}{\partial w}$$

Поскольку $y$ является константным вектором истинных меток, $\frac{\partial y}{\partial w} = 0$.

Найдем производную вектора вероятностей $p$ по вектору весов $w$. Производная каждого элемента $p_i$ по вектору $w$ равна:

$$\frac{\partial p_i}{\partial w} = \frac{\partial \sigma(w^T x_i)}{\partial w} = p_i (1 - p_i) x_i^T$$

Следовательно, Якобиан вектора $p$ по $w$ имеет размерность $N \times d$ и распадается на произведение диагональной матрицы $D$ и матрицы признаков $X$:

$$\frac{\partial p}{\partial w} = D X$$

где $D \in \mathbb{R}^{N \times N}$ — диагональная матрица дисперсий наблюдений:

$$D = \text{diag}\Big(p_1(1 - p_1), \, p_2(1 - p_2), \, \dots, \, p_N(1 - p_N)\Big)$$

Подставив полученный Якобиан в формулу матрицы Гессе, получаем:

$$H = \frac{1}{N} X^T D X$$

---

94. **Докажите выпуклость функции Log Loss.**

Функция $J(w)$ является выпуклой на пространстве $\mathbb{R}^d$ тогда и только тогда, когда её матрица Гессе $H(w)$ неотрицательно определена ($H(w) \succeq 0$) для любых $w \in \mathbb{R}^d$.

Матрица Гессе имеет вид $H = \frac{1}{N} X^T D X$.

1. Поскольку $p_i = \sigma(w^T x_i) \in (0, 1)$ для всех $z \in \mathbb{R}$, диагональные элементы матрицы $D$ строго положительны:

$$D_{ii} = p_i (1 - p_i) > 0 \quad \forall i \in \{1, \dots, N\}$$

Это означает, что диагональная матрица $D$ является строго положительно определённой ($D \succ 0$).

2. Проверим квадратичную форму $v^T H v$ для произвольного ненулевого вектора $v \in \mathbb{R}^d$:

$$v^T H v = v^T \left( \frac{1}{N} X^T D X \right) v = \frac{1}{N} (X v)^T D (X v)$$

Обозначим вектор $u = X v \in \mathbb{R}^N$. Вектор $u$ имеет компоненты $u_i = (X v)_i$. Перепишем квадратичную форму через суммы элементов:

$$v^T H v = \frac{1}{N} u^T D u = \frac{1}{N} \sum_{i=1}^{N} D_{ii} u_i^2 = \frac{1}{N} \sum_{i=1}^{N} p_i (1 - p_i) u_i^2$$

3. Поскольку $p_i(1 - p_i) > 0$ и $u_i^2 \ge 0$, каждое слагаемое в сумме является неотрицательным:

$$v^T H v \ge 0 \quad \forall v \in \mathbb{R}^d$$

Следовательно, матрица $H(w) \succeq 0$ является положительно полуопределённой во всех точках пространства параметров, что строго доказывает выпуклость функции Log Loss.

---

95. **Почему выпуклость гарантирует единственный глобальный минимум?**
 **Отсутствие локальных ловушек:** Для любой выпуклой функции на выпуклом множестве любой локальный минимум автоматически является глобальным минимумом. На графике функции потерь отсутствуют "локальные ямы", в которых итерационные алгоритмы оптимизации могли бы застрять с субоптимальным решением.
 **Единственность решения (Строгая выпуклость):** Если матрица признаков $X$ имеет полный столбцовый ранг $\text{rank}(X) = d$ (т.е. среди признаков нет линейно зависимых), то из $X v = 0$ следует $v = 0$. В этом случае $u = X v \neq 0$ для всех $v \neq 0$, а квадратичная форма становится строго положительной:

$$v^T H v > 0 \quad \forall v \neq 0$$

Матрица Гессе $H \succ 0$ становится строго положительно определённой, а функция Log Loss — строго выпуклой. Строгая выпуклость гарантирует, что точка глобального минимума $w^*$ существует и является строго единственной.

---

96. **Как работает метод Ньютона для логистической регрессии?**

Метод Ньютона (Ньютона-Рафсона) — это метод оптимизации второго порядка, который на каждом шаге аппроксимирует функцию потерь $J(w)$ квадратичным рядом Тейлора в окрестности текущей точки $w^{(k)}$:

$$J(w) \approx J(w^{(k)}) + \nabla J(w^{(k)})^T (w - w^{(k)}) + \frac{1}{2} (w - w^{(k)})^T H(w^{(k)}) (w - w^{(k)})$$

Приравнивая градиент этого квадратичного приближения по $w$ к нулю, получаем правило обновления весовых параметров:

$$w^{(k+1)} = w^{(k)} - H(w^{(k)})^{-1} \nabla J(w^{(k)})$$

Подставляем явные выражения для градиента и Гессиана логистической регрессии:

$$\nabla J(w^{(k)}) = \frac{1}{N} X^T (p^{(k)} - y)$$

$$H(w^{(k)}) = \frac{1}{N} X^T D^{(k)} X$$

Множители $\frac{1}{N}$ в числителе и знаменателе сокращаются, образуя итерационный шаг:

$$w^{(k+1)} = w^{(k)} - \left( X^T D^{(k)} X \right)^{-1} X^T (p^{(k)} - y)$$

Метод сходится за квадратичную скорость при близости к оптимуму, однако требует обращения матрицы $X^T D X$ размерности $d \times d$ на каждой итерации.

---

97. **Что такое IRLS и как он выводится?**

IRLS (Iteratively Reweighted Least Squares — итеративно взвешенный метод наименьших квадратов) — это форма записи алгоритма Ньютона-Рафсона для логистической регрессии, позволяющая сведать каждую итерацию к решению задачи взвешенного МНК.

Выведем IRLS из формулы метода Ньютона:

$$w^{(k+1)} = w^{(k)} - \left( X^T D^{(k)} X \right)^{-1} X^T (p^{(k)} - y)$$

Вынесем оператор $(X^T D^{(k)} X)^{-1} X^T D^{(k)}$ за скобки в левой части выражения:

$$w^{(k+1)} = \left( X^T D^{(k)} X \right)^{-1} \left[ (X^T D^{(k)} X) w^{(k)} - X^T (p^{(k)} - y) \right]$$

Вынесем $X^T$ влево, а $D^{(k)}$ вправо внутри скобок, учитывая, что $D^{(k)}$ — обратимая диагональная матрица с элементами $D_{ii}^{(k)} = p_i^{(k)}(1 - p_i^{(k)})$:

$$w^{(k+1)} = \left( X^T D^{(k)} X \right)^{-1} X^T D^{(k)} \left[ X w^{(k)} - (D^{(k)})^{-1} (p^{(k)} - y) \right]$$

Преобразуем выражение внутри квадратных скобок и введем рабочую переменную (adjusted response) $z^{(k)}$:

$$z^{(k)} = X w^{(k)} + (D^{(k)})^{-1} (y - p^{(k)})$$

Тогда обновление параметров на каждой итерации принимает вид классического решения взвешенного МНК (WLS):

$$w^{(k+1)} = \left( X^T D^{(k)} X \right)^{-1} X^T D^{(k)} z^{(k)}$$

На каждой итерации матрицы весов $D^{(k)}$ и откликов $z^{(k)}$ пересчитываются на основе текущих вероятностей $p^{(k)}$, после чего решается обычная система линейных уравнений.

---

98. **Почему Hessian положительно полуопределён?**

Положительная полуопределенность матрицы Гессе $H = \frac{1}{N} X^T D X$ вытекает из следующих фундаментальных свойств:

 **Диагональная матрица весов $D$:** Для логистической регрессии диагональные элементы $D_{ii} = p_i (1 - p_i)$. Поскольку функция сигмоиды строго ограничена $p_i \in (0, 1)$, произведение $p_i (1 - p_i)$ принимает максимальное значение $\frac{1}{4}$ при $p_i = 0.5$ и всегда строго больше нуля:

$$D_{ii} > 0 \quad \forall i \in \{1, \dots, N\}$$

 **Квадратичная форма от линейного преобразования:**
Для любого произвольного вектора $a \in \mathbb{R}^d$:

$$a^T H a = a^T \left( \frac{1}{N} X^T D X \right) a = \frac{1}{N} (X a)^T D (X a)$$

Обозначив $b = X a \in \mathbb{R}^N$, раскрываем произведение:

$$(X a)^T D (X a) = b^T D b = \sum_{i=1}^{N} D_{ii} b_i^2$$

Так как $D_{ii} > 0$ и квадрат любого реального числа $b_i^2 \ge 0$, их произведение и сумма всегда неотрицательны:

$$\sum_{i=1}^{N} D_{ii} b_i^2 \ge 0 \implies a^T H a \ge 0$$

Следовательно, матрица Гессе $H$ по определению является положительно полуопределенной ($H \succeq 0$).

99. **Сравните Gradient Descent, Newton и L-BFGS.**

| Характеристика | Gradient Descent (GD) | Метод Ньютона (Newton-Raphson) | L-BFGS (Limited-memory BFGS) |
| --- | --- | --- | --- |
| **Порядок метода** | Первого порядка (использует $\nabla J$) | Второго порядка (использует $\nabla J$ и $H$) | Квазиньютоновский (приближает $H^{-1}$) |
| **Сложность 1 итерации** | $O(N \cdot d)$ | $O(N \cdot d^2 + d^3)$ | $O(N \cdot d + m \cdot d)$ |
| **Затраты памяти** | $O(d)$ | $O(d^2)$ | $O(m \cdot d)$, где $m \ll d$ (обычно $m \in [5, 20]$) |
| **Скорость сходимости** | Линейная (требует много итераций) | Квадратичная (очень мало итераций) | Сверхлинейная (быстрее GD, дешевле Ньютона) |
| **Масштабируемость** | Высокая по $d$, средняя по $N$ | Низкая по $d$ (из-за обращения $d \times d$) | Высокая по $d$, высокая по $N$ |
| **Настройка параметров** | Требует подбора Learning Rate | Не требует подбора шага | Использует автоматический Line Search |

100. **Почему MSE приводит к плохим градиентам при использовании сигмоиды?**

Рассмотрим функцию среднеквадратичной ошибки (MSE) для одного объекта при использовании сигмоидальной функции активации:

$$J_{\text{MSE}}(w) = \frac{1}{2} (\sigma(z) - y)^2$$

где $z = w^T x$. Найдем градиент этой функции по весам $w$, используя правило дифференцирования сложной функции:

$$\frac{\partial J_{\text{MSE}}}{\partial w} = (\sigma(z) - y) \cdot \frac{\partial \sigma(z)}{\partial z} \cdot \frac{\partial z}{\partial w}$$

Подставим известную производную сигмоиды $\sigma'(z) = \sigma(z)(1 - \sigma(z))$:

$$\frac{\partial J_{\text{MSE}}}{\partial w} = (\sigma(z) - y) \cdot \sigma(z)(1 - \sigma(z)) \cdot x$$

Проанализируем полученный градиент в случае сильной ошибки модели (например, истинный класс $y = 1$, но модель выдает $z \ll 0$, то есть $\sigma(z) \to 0$):

 **Проблема затухания градиента (Vanishing Gradient):**
Когда модель выдает совершенно неверный результат ($\sigma(z) \to 0$ при $y = 1$), величины $(\sigma(z) - y) \approx -1$, но множитель производной сигмоиды стремится к нулю:

$$\lim_{z \to -\infty} \sigma(z)(1 - \sigma(z)) = 0 \cdot 1 = 0$$

В результате весь градиент $\frac{\partial J_{\text{MSE}}}{\partial w} \to 0$. Модель, совершая максимальную ошибку, практически останавливает своё обучение, так как шаг градиентного спуска становится близок к нулю.

 **Сравнение с Log Loss:**
В случае функции Log Loss множитель $\sigma(z)(1 - \sigma(z))$ в знаменателе производной функции потерь полностью сокращается с производной сигмоиды:

$$\frac{\partial J_{\text{LogLoss}}}{\partial w} = (\sigma(z) - y) x$$

Градиент пропорционален величине ошибки $(\sigma(z) - y)$ без затухающих множителей: чем больше ошибка, тем больше величина градиента и выше скорость обучения.

 **Нарушение выпуклости:**
Комбинация MSE и нелинейной сигмоиды делает итоговую функцию потерь невыпуклой (non-convex) со множеством локальных минимумов и плато, что препятствует гарантированному нахождению глобального оптимума.

## 11 Теорвер и Статистика
101. **Почему логистическая регрессия относится к обобщённым линейным моделям (GLM)?**

Класс обобщённых линейных моделей (Generalized Linear Models, GLM) объединяет модели, состоящие из трёх обязательных компонентов:

1. **Случайная компонента (Random Component):** Распределение условной целевой переменной $y \mid x$ должно принадлежать к однопараметрическому экспоненциальному семейству распределений. Для логистической регрессии бинарный отклик $y \in \{0, 1\}$ подчиняется распределению Бернулли с параметром $p = P(y = 1 \mid x)$.
2. **Систематическая компонента (Systematic Component):** Линейная комбинация признаков объекта $x$, формирующая линейный предиктор $\eta$:

$$\eta = w^T x = w_0 + w_1 x_1 + \dots + w_d x_d$$

3. **Функция связи (Link Function):** Монотонная гладкая функция $g(\cdot)$, связывающая математическое ожидание целевой переменной $\mu = E[y \mid x]$ с линейным предиктором $\eta$:

$$g(\mu) = \eta$$

В логистической регрессии математическое ожидание случайно величины Бернулли равно вероятности положительного исхода ($\mu = p$). В качестве функции связи $g(\cdot)$ используется logit-функция:

$$g(p) = \ln \left( \frac{p}{1 - p} \right) = \eta = w^T x$$

Выполнение всех трёх условий причисляет логистическую регрессию к семейству GLM.

---

102. **Какое распределение предполагается для целевой переменной?**

Для целевой переменной в логистической регрессии предполагается условное **распределение Бернулли** (Bernoulli distribution):

$$y_i \mid x_i \sim \text{Bernoulli}(p_i)$$

где $p_i = P(y_i = 1 \mid x_i)$ — вероятность того, что $i$-й объект принадлежит к положительному классу. Вероятность наблюдаемого значения $y_i \in \{0, 1\}$ выражается единой формулой вероятностной функции:

$$P(Y = y_i \mid x_i) = p_i^{y_i} (1 - p_i)^{1 - y_i}$$

Наблюдения $y_1, y_2, \dots, y_N$ предполагаются условно независимыми при заданных признаках $x_1, x_2, \dots, x_N$.

---

103. **Почему используется распределение Бернулли?**
104. **Естественная дискретность задачи:** В бинарной классификации пространство исходов состоит из двух взаимоисключающих альтернатив ($y \in \{0, 1\}$). Распределение Бернулли — единственное теоретико-вероятностное распределение, описывающее единичное испытание с двумя исходами.
105. **Зависимость дисперсии от математического ожидания:** Для бинарных случайных величин математическое ожидание $\mu = p$ однозначно определяет дисперсию:

$$\text{Var}(y \mid x) = p(1 - p) = \mu(1 - \mu)$$

Применение нормального распределения (как в классической регрессии) требовало бы постоянства дисперсии (гомоскедастичности), что физически невозможно для бинарного отклика.

3. **Корректное построение вероятностной модели:** Распределение Бернулли задаёт точный вид функции правдоподобия (Likelihood), максимизация которого приводит к корректным и состоятельным оценкам параметров модели.

---

104. **Что такое каноническая link-функция?**

Для любого распределения из экспоненциального семейства плотность (или функция вероятности) может быть записана в канонической форме:

$$f(y; \theta, \phi) = \exp \left( \frac{y \theta - b(\theta)}{a(\phi)} + c(y, \phi) \right)$$

где $\theta$ — естественный (канонический) параметр распределения, $\phi$ — параметр дисперсии, $b(\theta)$ — кумулянтная функция.

**Канонической link-функцией** $g(\mu)$ называется такая функция связи, которая напрямую приравнивает естественный параметр распределения $\theta$ к линейному предиктору $\eta$:

$$g(\mu) = \theta = \eta = w^T x$$

Использование канонической функции связи упрощает математические свойства модели: Гессиан функции потерь зависит только от признаков $x$ и предиктора $\eta$, а средние значения признаков в классах совпадают со взвешенными модельной вероятностью значениями (достаточные статистики совпадают).

---

105. **Почему logit является канонической link-функцией?**

Запишем функцию вероятности распределения Бернулли $P(y) = p^y (1 - p)^{1 - y}$ в форме экспоненциального семейства, взяв от неё экспоненту и логарифм:

$$P(y) = \exp \left( \ln \left( p^y (1 - p)^{1 - y} \right) \right)$$

Преобразуем выражение под экспонентой с помощью свойств логарифма:

$$P(y) = \exp \left( y \ln p + (1 - y) \ln(1 - p) \right) = \exp \left( y \ln p + \ln(1 - p) - y \ln(1 - p) \right)$$

Сгруппируем слагаемые при $y$:

$$P(y) = \exp \left( y \ln \left( \frac{p}{1 - p} \right) + \ln(1 - p) \right)$$

Сравнивая с канонической формой экспоненциального семейства $f(y) = \exp(y \theta - b(\theta))$, находим естественный параметр $\theta$:

$$\theta = \ln \left( \frac{p}{1 - p} \right)$$

Так как математическое ожидание $\mu = E[y] = p$, приравнивание естественного параметра к линейному предиктору $\theta = \eta$ даёт:

$$\eta = \ln \left( \frac{\mu}{1 - \mu} \right) = \text{logit}(\mu)$$

Следовательно, logit-функция $g(\mu) = \text{logit}(\mu)$ по определению является канонической функцией связи для распределения Бернулли.

106. **Выведите ожидаемое значение и дисперсию распределения Бернулли.**

Пусть дискретная случайная величина $Y \sim \text{Bernoulli}(p)$ принимает значение $1$ с вероятностью $p$ и значение $0$ с вероятностью $1 - p$.

1. **Вывод математического ожидания $E[Y]$:**
По определению математического ожидания для дискретной случайной величины:

$$E[Y] = \sum_{k \in \{0, 1\}} k \cdot P(Y = k)$$

$$E[Y] = 0 \cdot (1 - p) + 1 \cdot p = p$$

2. **Вывод дисперсии $\text{Var}(Y)$:**
Дисперсия выражается через начальные моменты первого и второго порядка:

$$\text{Var}(Y) = E[Y^2] - (E[Y])^2$$

Вычислим математическое ожидание квадрата случайной величины $E[Y^2]$:

$$E[Y^2] = \sum_{k \in \{0, 1\}} k^2 \cdot P(Y = k)$$

$$E[Y^2] = 0^2 \cdot (1 - p) + 1^2 \cdot p = p$$

Подставим $E[Y^2] = p$ и $E[Y] = p$ в формулу дисперсии:

$$\text{Var}(Y) = p - p^2 = p(1 - p)$$

107. **Что такое Fisher Information?**

**Информация Фишера** (Fisher Information) — это мера количества информации, которую наблюдаемая случайная величина содержит о неизвестном параметре $\theta$ вероятностной модели.

Математически информация Фишера $I(\theta)$ определяется как дисперсия скор-функции (градиента логарифма правдоподобия):

$$I(\theta) = \text{Var}\left( \nabla_\theta \ln L(\theta) \right) = E \left[ \left( \nabla_\theta \ln L(\theta) \right) \left( \nabla_\theta \ln L(\theta) \right)^T \right]$$

При выполнении условий регулярности дифференцирования информация Фишера равна математическому ожиданию матрицы Гессе логарифмического правдоподобия, взятому с противоположным знаком:

$$I(\theta) = -E \left[ \nabla_\theta^2 \ln L(\theta) \right]$$

Для логистической регрессии с $N$ наблюдениями логарифм правдоподобия $\ell(w)$ не зависит от реализации случайной величины в Гессиане, поэтому матрица информации Фишера совпадает с матрицей Гессе функции потерь (без усреднения по выборке):

$$I(w) = X^T D X$$

где $D = \text{diag}(p_1(1 - p_1), \dots, p_N(1 - p_N))$.

108. **Как вычисляется ковариационная матрица оценок?**

Согласно асимптотической теории методов максимального правдоподобия (MLE), асимптотическая ковариационная матрица оценки вектора параметров $\hat{w}$ равна обратной матрице информации Фишера, рассчитанной в точке оптимума $\hat{w}$:

$$\text{Cov}(\hat{w}) = I(\hat{w})^{-1}$$

Подставляя выражение матрицы информации Фишера для логистической регрессии, получаем:

$$\text{Cov}(\hat{w}) = \left( X^T \hat{D} X \right)^{-1}$$

где $\hat{D}$ — диагональная матрица размера $N \times N$, содержащая оценки дисперсий наблюдений при оптимальных весах:

$$\hat{D}_{ii} = \hat{p}_i (1 - \hat{p}_i), \quad \hat{p}_i = \sigma(X_i \hat{w})$$

Диагональные элементы полученной матрицы $\text{Cov}(\hat{w})_{jj}$ представляют собой дисперсии оценок соответствующих коэффициентов $\hat{w}_j$, а их квадратные корни — стандартные ошибки оценок $\text{SE}(\hat{w}_j)$:

$$\text{SE}(\hat{w}_j) = \sqrt{\left[ (X^T \hat{D} X)^{-1} \right]_{jj}}$$

109. **Почему оценки MLE асимптотически нормальны?**

Асимптотическая нормальность оценок максимального правдоподобия выводится из разложения скор-функции $\nabla \ell(\hat{w}) = 0$ в ряд Тейлора первого порядка вокруг истинного значения параметров $w_0$:

$$0 = \nabla \ell(\hat{w}) \approx \nabla \ell(w_0) + \nabla^2 \ell(w_0)(\hat{w} - w_0)$$

Выразим отклонение оценки $(\hat{w} - w_0)$:

$$(\hat{w} - w_0) \approx -\left[ \nabla^2 \ell(w_0) \right]^{-1} \nabla \ell(w_0)$$

Умножим обе части на $\sqrt{N}$:

$$\sqrt{N}(\hat{w} - w_0) \approx \left[ -\frac{1}{N} \nabla^2 \ell(w_0) \right]^{-1} \left( \frac{1}{\sqrt{N}} \nabla \ell(w_0) \right)$$

1. **Центральная предельная теорема (ЦПТ):** Скор-функция $\nabla \ell(w_0) = \sum_{i=1}^N (y_i - p_i) x_i$ является суммой $N$ независимых одинаково распределенных случайных векторов с нулевым математическим ожиданием $E[\nabla \ell(w_0)] = 0$ и ковариационной матрицей $I_1(w_0)$. По ЦПТ:

$$\frac{1}{\sqrt{N}} \nabla \ell(w_0) \xrightarrow{d} \mathcal{N}\left(0, I_1(w_0)\right)$$

2. **Закон больших чисел (ЗБЧ):** Нормированная матрица Гессе по ЗБЧ сходится по вероятности к матрице информации Фишера для одного наблюдения:

$$-\frac{1}{N} \nabla^2 \ell(w_0) \xrightarrow{P} I_1(w_0)$$

3. **Теорема Слуцкого:** Применение теоремы Слуцкого к произведению дает сходимость по распределению к многомерному нормальному распределению:

$$\sqrt{N}(\hat{w} - w_0) \xrightarrow{d} \mathcal{N}\left(0, I_1(w_0)^{-1}\right)$$

Или в конечном виде для выборки объема $N$:

$$\hat{w} \overset{a}{\sim} \mathcal{N}\left(w_0, I(w_0)^{-1}\right) = \mathcal{N}\left(w_0, (X^T D X)^{-1}\right)$$

110. **Как выводятся доверительные интервалы коэффициентов?**

Вывод двустороннего доверительного интервала для коэффициента $w_j$ уровня доверия $(1 - \alpha)$ основывается на асимптотической нормальности оценки $\hat{w}_j$:

$$\hat{w}_j \overset{a}{\sim} \mathcal{N}\left(w_j, \text{SE}(\hat{w}_j)^2\right)$$

Сконструируем стандартизованную статистику Вальда $Z$:

$$Z = \frac{\hat{w}_j - w_j}{\text{SE}(\hat{w}_j)} \overset{a}{\sim} \mathcal{N}(0, 1)$$

Для стандартного нормального распределения вероятность того, что статистика $Z$ находится в интервале $[-z_{1 - \alpha/2}, \, z_{1 - \alpha/2}]$, равна $(1 - \alpha)$:

$$P\left( -z_{1 - \alpha/2} \le \frac{\hat{w}_j - w_j}{\text{SE}(\hat{w}_j)} \le z_{1 - \alpha/2} \right) = 1 - \alpha$$

где $z_{1 - \alpha/2}$ — квантиль уровня $(1 - \alpha/2)$ стандартного нормального распределения (например, $1.96$ для $\alpha = 0.05$).

Преобразуем двойное неравенство относительно истинного параметра $w_j$:

$$-z_{1 - \alpha/2} \cdot \text{SE}(\hat{w}_j) \le \hat{w}_j - w_j \le z_{1 - \alpha/2} \cdot \text{SE}(\hat{w}_j)$$

Умножим неравенство на $-1$ и прибавим $\hat{w}_j$:

$$\hat{w}_j - z_{1 - \alpha/2} \cdot \text{SE}(\hat{w}_j) \le w_j \le \hat{w}_j + z_{1 - \alpha/2} \cdot \text{SE}(\hat{w}_j)$$

Итоговый асимптотический доверительный интервал для коэффициента $w_j$:

$$\text{CI}_{1-\alpha}(w_j) = \left[ \hat{w}_j - z_{1 - \alpha/2} \sqrt{\left[(X^T \hat{D} X)^{-1}\right]_{jj}}, \quad \hat{w}_j + z_{1 - \alpha/2} \sqrt{\left[(X^T \hat{D} X)^{-1}\right]_{jj}} \right]$$

111. **Докажите состоятельность оценок MLE.**

Состоятельность оценки максимального правдоподобия (MLE) означают, что при стремлении объёма выборки к бесконечности оценка $\hat{w}_n$ сходится по вероятности к истинному значению параметра $w_0$:

$$\hat{w}_n \xrightarrow{p} w_0 \quad \text{при } n \to \infty$$

Рассмотрим нормированную функцию логарифмического правдоподобия $M_n(w)$:

$$M_n(w) = \frac{1}{n} \ln L(w) = \frac{1}{n} \sum_{i=1}^{n} \left[ y_i w^T x_i - \ln(1 + e^{w^T x_i}) \right]$$

По Слабому закону больших чисел (WLLN) для каждого фиксированного $w$ точка $M_n(w)$ сходится по вероятности к своему математическому ожиданию $M_0(w)$:

$$M_0(w) = \mathbb{E}_{X,Y} \left[ Y w^T X - \ln(1 + e^{w^T X}) \right]$$

Разность $M_0(w) - M_0(w_0)$ выражается через отрицательную дивергенцию Кульбака-Лейблера ($D_{\text{KL}}$) между распределениями $P_{w_0}(Y \mid X)$ и $P_w(Y \mid X)$:

$$M_0(w) - M_0(w_0) = -\mathbb{E}_X \left[ D_{\text{KL}}\left( P_{w_0}(Y \mid X) \,\vert{}\vert{}\, P_w(Y \mid X) \right) \right]$$

По свойствам дивергенции Кульбака-Лейблера $D_{\text{KL}}(P_{w_0} \,\vert{}\vert{}\, P_w) \ge 0$, причём равенство нулю достигается тогда и только тогда, когда $P_w = P_{w_0}$. Следовательно, предельная функция $M_0(w)$ имеет строгий локальный и глобальный максимум в точке $w = w_0$.

При условиях невырожденности матрицы признаков (когда $M_0(w)$ строго выпукла) и компактности области параметров $W$, Равномерный закон больших чисел гарантирует равномерную сходимость:

$$\sup_{w \in W} \vert{}M_n(w) - M_0(w)\vert{} \xrightarrow{p} 0$$

Из равномерной сходимости непрерывных функций и строгого максимума в точке $w_0$ по теореме о состоятельности M-оценок следует:

$$\hat{w}_n = \arg\max_{w \in W} M_n(w) \xrightarrow{p} w_0$$

112. **Докажите асимптотическую нормальность MLE.**

Оценка максимального правдоподобия $\hat{w}_n$ удовлетворяет условию первого порядка для скор-функции $S_n(w) = \nabla_w M_n(w)$:

$$S_n(\hat{w}_n) = \frac{1}{n} \sum_{i=1}^{n} \left( y_i - \sigma(\hat{w}_n^T x_i) \right) x_i = 0$$

Разложим скор-функцию $S_n(\hat{w}_n)$ в векторный ряд Тейлора в окрестности истинного параметра $w_0$:

$$0 = S_n(\hat{w}_n) = S_n(w_0) + H_n(\bar{w})(\hat{w}_n - w_0)$$

где $\bar{w}$ — промежуточная точка на отрезке между $\hat{w}_n$ и $w_0$, а $H_n(w) = \nabla_w^2 M_n(w)$ — нормализованная матрица Гессе:

$$H_n(w) = -\frac{1}{n} X^T D(w) X = -\frac{1}{n} \sum_{i=1}^{n} \sigma(w^T x_i)(1 - \sigma(w^T x_i)) x_i x_i^T$$

Выразим нормированную разность $\sqrt{n}(\hat{w}_n - w_0)$:

$$\sqrt{n}(\hat{w}_n - w_0) = \left( -H_n(\bar{w}) \right)^{-1} \sqrt{n} S_n(w_0)$$

1. По Центральной предельной теореме (ЦПТ) для суммы независимых случайно величин с нулевым математическим ожиданием $E[S_n(w_0)] = 0$:

$$\sqrt{n} S_n(w_0) = \frac{1}{\sqrt{n}} \sum_{i=1}^{n} (y_i - \sigma(w_0^T x_i)) x_i \xrightarrow{d} \mathcal{N}\left(0, \, I_1(w_0)\right)$$

где $I_1(w_0) = \mathbb{E}\left[ \sigma(w_0^T X)(1 - \sigma(w_0^T X)) X X^T \right]$ — матрица информации Фишера для одного наблюдения.

2. По Закону больших чисел и состоятельности $\hat{w}_n \xrightarrow{p} w_0$ средний Гессиан сходится по вероятности к матрице информации Фишера:

$$-H_n(\bar{w}) \xrightarrow{p} I_1(w_0)$$

Применяя теорему Слуцкого о произведении сходящихся по распределению и по вероятности последовательностей:

$$\sqrt{n}(\hat{w}_n - w_0) \xrightarrow{d} I_1(w_0)^{-1} \cdot \mathcal{N}\left(0, I_1(w_0)\right) = \mathcal{N}\left(0, \, I_1(w_0)^{-1}\right)$$

113. **Выведите уравнения score function.**

Скор-функция (Score function) $S(w)$ представляет собой вектор градиента логарифмической функции правдоподобия $\ell(w)$ по вектору параметров $w$:

$$S(w) = \nabla_w \ell(w)$$

Запишем логарифм правдоподобия выборки объемa $N$:

$$\ell(w) = \sum_{i=1}^{N} \left[ y_i \ln p_i + (1 - y_i) \ln(1 - p_i) \right]$$

где $p_i = \sigma(z_i)$ и $z_i = w^T x_i$. Продифференцируем $\ell(w)$ по вектору $w$:

$$\nabla_w \ell(w) = \sum_{i=1}^{N} \left[ \frac{y_i}{p_i} \nabla_w p_i - \frac{1 - y_i}{1 - p_i} \nabla_w p_i \right] = \sum_{i=1}^{N} \left[ \frac{y_i - p_i}{p_i(1 - p_i)} \right] \nabla_w p_i$$

Учитывая, что градиент сигмоиды равен $\nabla_w p_i = \sigma'(z_i) x_i = p_i (1 - p_i) x_i$:

$$S(w) = \sum_{i=1}^{N} \left[ \frac{y_i - p_i}{p_i(1 - p_i)} \right] p_i (1 - p_i) x_i$$

Сокращая множители $p_i (1 - p_i)$ в числителе и знаменателе, получаем систему уравнений скор-функции:

$$S(w) = \sum_{i=1}^{N} (y_i - p_i) x_i = X^T (y - p)$$

Уравнения правдоподобия $S(w) = 0$ означают, что в точке оптимума вектор ошибок предсказания $(y - p)$ ортогонален пространству признаков $X$.

114. **Что такое Cramér–Rao Lower Bound?**

Граница Крамера-Рао (Cramér–Rao Lower Bound, CRLB) задаёт теоретический нижний предел дисперсии для любой несмещённой оценки неизвестного параметра $w$.

Пусть $\hat{w}$ — несмещённая оценка вектора параметров $w \in \mathbb{R}^d$, то есть $\mathbb{E}[\hat{w}] = w$. Тогда ковариационная матрица ошибки оценки $\text{Cov}(\hat{w})$ удовлетворяет матричному неравенству:

$$\text{Cov}(\hat{w}) \succeq I(w)^{-1}$$

где $I(w)$ — матрица информации Фишера объёма выборки:

$$I(w) = \mathbb{E} \left[ \left( \nabla_w \ln L(w) \right) \left( \nabla_w \ln L(w) \right)^T \right] = -\mathbb{E} \left[ \nabla_w^2 \ln L(w) \right]$$

Матричное неравенство $A \succeq B$ означает, что разность $(A - B)$ является положительно полуопределённой матрицей.

Оценка, достигает границы Крамера-Рао (для которой $\text{Cov}(\hat{w}) = I(w)^{-1}$), называется **эффективной**. Оценка максимального правдоподобия (MLE) в логистической регрессии не является строго эффективной на конечных выборках, но является **асимптотически эффективной**, то есть асимптотически достигает границы Крамера-Рао при $N \to \infty$.

115. **Почему логистическая регрессия является выпуклой задачей оптимизации?**

Задача оптимизации логистической регрессии сводится к минимизации функции потерь $J(w)$ на некотором множестве допустимых значений $\Omega$:

$$\min_{w \in \Omega} J(w)$$

Задача является выпуклой, если выполнены два условия:

1. **Выпуклость множества допустимых решений:** Пространство параметров $\Omega = \mathbb{R}^d$ является выпуклым множеством по определению (для любых $w_1, w_2 \in \mathbb{R}^d$ и $\lambda \in [0, 1]$ отрезок $\lambda w_1 + (1-\lambda) w_2 \in \mathbb{R}^d$).
2. **Выпуклость целевой функции:** Функция $J(w) = \frac{1}{N} \sum_{i=1}^{N} \ln(1 + e^{-y_i^* w^T x_i})$ (где $y_i^* \in \{-1, +1\}$) должна иметь положительно полуопределённую матрицу Гессе $H(w) \succeq 0$ во всех точках.

Вычислим Гессиан $H(w)$:

$$H(w) = \frac{1}{N} X^T D X$$

где $D$ — диагональная матрица с элементами $D_{ii} = p_i(1 - p_i)$. Поскольку $p_i \in (0, 1)$, скаляр $D_{ii} > 0$. Для любого вектора $v \in \mathbb{R}^d$:

$$v^T H v = \frac{1}{N} (X v)^T D (X v) = \frac{1}{N} \sum_{i=1}^{N} D_{ii} (x_i^T v)^2 \ge 0$$

Так как $v^T H v \ge 0$ для любого $v$, матрица $H(w)$ положительно полуопределена. Наличие выпуклой целевой функции на выпуклом множестве делает логистическую регрессию выпуклой задачей оптимизации.

116. **Как выглядит двойственная задача (dual formulation)?**

Рассмотрим прямую задачу минимизации $L_2$-регуляризованной логистической регрессии с целевыми метками $y_i \in \{-1, +1\}$:

$$\min_{w \in \mathbb{R}^d} \frac{1}{2} \Vert{}w\Vert{}^2 + C \sum_{i=1}^{N} \ln\left(1 + e^{-y_i w^T x_i}\right)$$

Введём вспомогательные переменные $u_i = y_i w^T x_i$. Задача принимает вид с равенствами-ограничениями:

$$\min_{w, u} \frac{1}{2} \Vert{}w\Vert{}^2 + C \sum_{i=1}^{N} \ln\left(1 + e^{-u_i}\right) \quad \text{при условии } u_i = y_i w^T x_i \quad \forall i$$

Запишем функцию Лагранжа с двойственными переменными $\alpha_i$:

$$\mathcal{L}(w, u, \alpha) = \frac{1}{2} \Vert{}w\Vert{}^2 + C \sum_{i=1}^{N} \ln\left(1 + e^{-u_i}\right) + \sum_{i=1}^{N} \alpha_i \left( u_i - y_i w^T x_i \right)$$

Найдём условия стационарности по прямым переменным $w$ и $u_i$:

$$\nabla_w \mathcal{L} = w - \sum_{i=1}^{N} \alpha_i y_i x_i = 0 \implies w = \sum_{i=1}^{N} \alpha_i y_i x_i$$

$$\frac{\partial \mathcal{L}}{\partial u_i} = -C \frac{e^{-u_i}}{1 + e^{-u_i}} + \alpha_i = 0 \implies \alpha_i = C \sigma(-u_i) \in (0, C)$$

Выразив $u_i$ через $\alpha_i$, сопряжённая по Фенхелю функция логистической потери имеет вид:

$$f^*(\alpha_i) = \alpha_i \ln \left( \frac{\alpha_i}{C} \right) + (C - \alpha_i) \ln \left( 1 - \frac{\alpha_i}{C} \right)$$

Подставляя оптимизированные $w$ и $u$ обратно в Лагранжиан, получаем **двойственную задачу оптимизации** относительно $\alpha$:

$$\max_{\alpha \in \mathbb{R}^N} -\frac{1}{2} \sum_{i=1}^{N} \sum_{j=1}^{N} \alpha_i \alpha_j y_i y_j x_i^T x_j - \sum_{i=1}^{N} \left[ \alpha_i \ln \alpha_i + (C - \alpha_i) \ln (C - \alpha_i) \right] + C N \ln C$$

$$\text{при ограничениях: } 0 \le \alpha_i \le C \quad \forall i \in \{1, \dots, N\}$$

117. **Как связана логистическая регрессия с максимальной энтропией?**

Принцип максимальной энтропии (MaxEnt) утверждает, что среди всех вероятностных распределений, удовлетворяющих заданным ограничениям, следует выбирать распределение с наибольшей информационной энтропией (наименее смещённое).

Сформулируем задачу нахождения условного распределения $p(y \mid x)$ с максимальной энтропией:

$$\max_{p} H(Y \mid X) = \max_{p} \left( -\sum_{x} \sum_{y \in \{0,1\}} p(x) p(y \mid x) \ln p(y \mid x) \right)$$

при условиях:

1. Нормировка вероятностей: $\sum_{y} p(y \mid x) = 1$ для всех $x$.
2. Совпадение эмпирических и модельных математических ожиданий признаков $f_k(x, y) = y x_k$:

$$\mathbb{E}_p [y x_k] = \mathbb{E}_{\hat{p}} [y x_k] \implies \sum_{x} p(x) \sum_{y} p(y \mid x) y x_k = \frac{1}{N} \sum_{i=1}^{N} y_i x_{i,k}$$

Запишем функционал Лагранжа с множителями $\mu(x)$ для нормировки и $w_k$ для условий на моменты признаков:

$$\mathcal{L}(p, \mu, w) = -\sum_{x, y} p(x) p(y \mid x) \ln p(y \mid x) - \sum_{x} \mu(x) \left( \sum_{y} p(y \mid x) - 1 \right) - \sum_k w_k \left( \sum_{x, y} p(x) p(y \mid x) y x_k - C_k \right)$$

Приравняем частную производную по $p(y=1 \mid x)$ к нулю:

$$\frac{\partial \mathcal{L}}{\partial p(y=1 \mid x)} = -p(x) \left( \ln p(y=1 \mid x) + 1 \right) - \mu(x) - p(x) w^T x = 0$$

Выразим $p(y=1 \mid x)$:

$$p(y=1 \mid x) = \exp\left( -1 - \frac{\mu(x)}{p(x)} \right) \cdot \exp(w^T x)$$

Используя условие нормировки $p(y=0 \mid x) + p(y=1 \mid x) = 1$:

$$p(y=1 \mid x) = \frac{\exp(w^T x)}{1 + \exp(w^T x)} = \frac{1}{1 + e^{-w^T x}} = \sigma(w^T x)$$

Таким образом, распределение с максимальной энтропией при линейных ограничениях на моменты признаков математически эквивалентно модели логистической регрессии.

118. **Чем отличается дискриминативная модель от генеративной с математической точки зрения?**

Главное математическое различие заключается в типе моделируемой вероятности и объекте оптимизации:

1. **Генеративные модели (Generative Models):**
Моделируют совместное распределение вероятностей признаков и меток $P(X, Y) = P(X \mid Y) P(Y)$.

* Примеры: Гауссовский дискриминантный анализ (LDA/QDA), Наивный Байес.
* Оптимизируют совместное правдоподобие:

$$\max \prod_{i=1}^{N} P(x_i, y_i) = \max \prod_{i=1}^{N} P(x_i \mid y_i) P(y_i)$$

* Для классификации используют правило Байеса:

$$P(Y = 1 \mid X) = \frac{P(X \mid Y = 1) P(Y = 1)}{P(X \mid Y = 1) P(Y = 1) + P(X \mid Y = 0) P(Y = 0)}$$

2. **Дискриминативные модели (Discriminative Models):**
Моделируют напрямую условное распределение целевого класса $P(Y \mid X)$, не тратя ресурсы на аппроксимацию распределения признаков $P(X)$.

* Примеры: Логистическая регрессия, Метод опорных векторов (SVM).
* Оптимизируют условное правдоподобие:

$$\max \prod_{i=1}^{N} P(y_i \mid x_i)$$

Если в генеративной модели LDA распределения классов $P(X \mid Y = k)$ нормальны с одинаковой ковариационной матрицей $\Sigma$, то апостериорная вероятность $P(Y=1 \mid X)$ математически точно сводится к форме сигмоиды $P(Y=1 \mid X) = \sigma(w^T X + b)$. Однако логистическая регрессия требует меньше априорных предположений о форме распределения $P(X)$.

119. **Как вывести Softmax Regression как обобщение бинарной логистической регрессии?**

В бинарной логистической регрессии отношение вероятностей двух классов выражается через log-odds:

$$\ln \left( \frac{P(Y = 1 \mid x)}{P(Y = 0 \mid x)} \right) = w^T x$$

Обобщим это соотношение на случай $K$ классов, выбрав $K$-й класс в качестве базoвого (эталонного) класса. Запишем логарифм отношения вероятностей $k$-го класса к $K$-му классу в виде линейной модели:

$$\ln \left( \frac{P(Y = k \mid x)}{P(Y = K \mid x)} \right) = w_k^T x, \quad k \in \{1, \dots, K-1\}$$

Проэкспонируем обе части уравнения:

$$P(Y = k \mid x) = P(Y = K \mid x) \cdot e^{w_k^T x}$$

Для базового $K$-го класса зафиксируем вектор весов $w_K = 0$, тогда $e^{w_K^T x} = e^0 = 1$.

Используем условие полной вероятности для всех $K$ классов:

$$\sum_{j=1}^{K} P(Y = j \mid x) = 1$$

Подставим полученные выражения в сумму:

$$\sum_{j=1}^{K} P(Y = K \mid x) \cdot e^{w_j^T x} = 1 \implies P(Y = K \mid x) \sum_{j=1}^{K} e^{w_j^T x} = 1$$

Выразим вероятность базового класса:

$$P(Y = K \mid x) = \frac{1}{\sum_{j=1}^{K} e^{w_j^T x}}$$

Теперь подставим $P(Y = K \mid x)$ в формулу для любого произвольного класса $k \in \{1, \dots, K\}$:

$$P(Y = k \mid x) = \frac{e^{w_k^T x}}{\sum_{j=1}^{K} e^{w_j^T x}}$$

Полученное выражение является функцией **Softmax**. При $K = 2$ она сводится к стандартной бинарной сигмоиде:

$$P(Y = 1 \mid x) = \frac{e^{w_1^T x}}{e^{w_1^T x} + e^{w_2^T x}} = \frac{1}{1 + e^{-(w_1 - w_2)^T x}} = \sigma((w_1 - w_2)^T x)$$

120. **Как доказать, что Cross-Entropy является отрицательным логарифмом правдоподобия?**

Кросс-энтропия между истинным эмпирическим распределением меток $q(y \mid x_i)$ и предсказанным модельным распределением $p(y \mid x_i; w)$ на одном объекте $x_i$ по определению теории информации равна:

$$H(q, p)_i = -\sum_{k=1}^{K} q(Y = k \mid x_i) \ln p(Y = k \mid x_i; w)$$

Для классификации целевая метка задаётся индикатором однократного выбора (one-hot encoding): $q(Y = k \mid x_i) = \mathbb{I}(y_i = k)$. Тогда суммирование по классам оставляет только истинный класс:

$$H(q, p)_i = -\ln p(Y = y_i \mid x_i; w)$$

Усредняя значение кросс-энтропии по всем $N$ объектам обучающей выборки, получаем эмпирический функционал кросс-энтропии:

$$\text{CrossEntropy}(w) = -\frac{1}{N} \sum_{i=1}^{N} \ln p(Y = y_i \mid x_i; w)$$

С другой стороны, функция правдоподобия $L(w)$ для независимых наблюдений равна произведению вероятностей наблюдаемых меток:

$$L(w) = \prod_{i=1}^{N} P(Y = y_i \mid x_i; w)$$

Возьмем отрицательный логарифм от правдоподобия (Negative Log-Likelihood, NLL) и нормируем его на число объектов $N$:

$$\text{NLL}(w) = -\frac{1}{N} \ln L(w) = -\frac{1}{N} \ln \left( \prod_{i=1}^{N} P(Y = y_i \mid x_i; w) \right) = -\frac{1}{N} \sum_{i=1}^{N} \ln P(Y = y_i \mid x_i; w)$$

Сравнивая выражения, получаем тождество:

$$\text{CrossEntropy}(w) \equiv \text{NLL}(w) = -\frac{1}{N} \ln L(w)$$

Таким образом, минимизация кросс-энтропии фундаментально эквивалентна минимизации отрицательного логарифма правдоподобия.
