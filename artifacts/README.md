# Артефакты

`<dataset>/<model>/<run_id>/` — отдельный запуск.
`<dataset>/classical/legacy/` — перенесённые исторические результаты.

Новые запуски имеют `config.json`, `split.json`, `run.json` и
`run_metrics.json`. Статус `completed` означает успешное завершение.
Если обучение прервано, каталог остаётся со статусом `running` для диагностики.
Времена в идентификаторах каталогов указаны в UTC.
