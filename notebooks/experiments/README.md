# Сравнение экспериментов

Здесь размещаются исследовательские ноутбуки для сравнения классических
моделей и нейросетей. Обучающий код остаётся в `src/`, воспроизводимые
запуски — в `scripts/`. Результаты следует читать из `artifacts/`.
Проверяйте совпадение внешнего разбиения по `split.json` и протокола оценки.
