# Глубокое обучение

Теоретические конспекты в формате Jupyter Notebook. Реализаций нейросетей пока нет.

- [Обратное распространение ошибки](backpropagation.ipynb) — цепное правило,
  вычислительный граф, прямой и обратный проходы, ручной пример, градиенты
  полносвязного слоя и проверка производных. По мотивам
  [слайдов Филиппа Ульянкина](https://github.com/FUlyankin/deep_learning_pytorch/blob/main/week04_backprop/nn_slides_4.pdf).
  Ноутбук содержит только пояснения, формулы и схему, без исполняемых ячеек.

Открыть из корня проекта:

```bash
jupyter lab tutorials/deep/backpropagation.ipynb
```
